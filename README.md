# Lab-Exercise-2

## Aim: 
To design and develop a mobile application and web layout by applying Gestalt Principles.


## Algorithm:
1. Open the TasteBite application.

2. Display the Home Screen.

3. User searches or selects a food category.

4. Display available restaurants.

5. User selects a restaurant.

6. Display restaurant menu and food items.

7. User selects a food item.

8. Add the selected item to the cart.

9. Display the cart with selected items and total price.

10. User clicks Checkout.

11. Display order confirmation.
